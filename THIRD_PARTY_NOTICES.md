# Créditos de terceros

## Fuentes SVG

Las fuentes SVG conservan sus metadatos originales de autoría y licencia. Provienen de la colección [SVG Fonts de Windell H. Oskay](https://gitlab.com/oskay/svg-fonts), enlazada desde [Hershey Text](https://wiki.evilmadscientist.com/Hershey_Text).

- **EMS:** SIL Open Font License 1.1; se incluye [OFL-EMS.txt](fonts/OFL-EMS.txt) del distribuidor original. Sheldon B. Michaels creó los derivados y Windell H. Oskay convirtió los SVG. Los diseñadores originales se indican en cada archivo.
- **Hershey:** condiciones y reconocimientos completos dentro de los metadatos de cada SVG, incluyendo atribución a Dr. A. V. Hershey y restricciones del formato original.
- Se conserva además [LICENSE-hersheytext.txt](fonts/LICENSE-hersheytext.txt), aviso MIT de copyright 2014 James T. Ese aviso no sustituye las licencias específicas de las fuentes EMS o Hershey.

## Dependencias

Flask, NumPy, Pillow, OpenCV y Eclipse Paho MQTT se instalan desde sus distribuciones. Playwright se usa sólo para pruebas del editor. Cada dependencia conserva su licencia propia; este repositorio no distribuye sus entornos instalados.

El proyecto Android usa Gradle, el plugin Android y Chaquopy. Se incluye el wrapper de Gradle para compilar; los productos de compilación y la configuración local del SDK están excluidos.

## Código propio

No se ha elegido una licencia general para el código propio de Pluma A1. Publicar el repositorio no sustituye esa elección ni modifica las licencias de los componentes de terceros.
